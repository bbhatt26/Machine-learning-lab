# Project 2: Disease Prediction System
Inputs: age, temperature, systolic blood pressure, pulse rate and symptom indicators.
Preprocessing: median imputation and standard scaling for numeric features; most-frequent imputation for symptom indicators.
Algorithms: Logistic Regression, Decision Tree, Random Forest and Gradient Boosting.
Evaluation: accuracy, weighted precision/recall/F1, classification report and confusion matrix.
Run `python train_model.py`, then `streamlit run app.py`.
**Important:** Synthetic-data classroom exercise only; not a diagnostic or clinical decision-support system.
